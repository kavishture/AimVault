Import Code

In Valorant: Settings → Crosshair → Import Profile Code, paste the code above, then Confirm. Codes follow the community-reverse-engineered 0;P;…;A;…;S;… schema (color c/u, outlines h, center dot d/z, inner/outer lines prefixed 0/1 for show, length l, thickness t, offset o, opacity a, error toggles f/m, sniper scale s). Loading a code always drops you on the Primary tab — switch to ADS / Sniper Scoped to see those profiles if the code sets them separately (e.g. a code with a different Sniper color won't show it until you click that tab). One known gap: a handful of codes carry separate horizontal/vertical values for one axis (an "unlinked" advanced option) — this reader uses the primary value for both, so those specific codes may render very slightly asymmetric compared to in-game.
