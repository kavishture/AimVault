Why this version is code-first

AimVault's main page is intentionally separate from the crosshair generator. The page does not generate new Valorant codes or rewrite imported codes. It only reads the supplied code for a visual preview and keeps the original string available to copy. This avoids the inaccurate code-generation problem while the dedicated generator can be added later.
