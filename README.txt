AIMVAULT - GITHUB VERSION

IMPORTANT: Keep these files at the repository root:
index.html
style.css
app.js
crosshairs.js
logo.svg

Images go in:
images/crosshairs/

HOW TO ADD A CROSSHAIR
1. Put your image in images/crosshairs/
2. Open crosshairs.js
3. Add an object inside CROSSHAIRS:
{
  id: "my-crosshair",
  name: "My Crosshair",
  image: "images/crosshairs/my-crosshair.png",
  code: "MY_VALORANT_CODE",
  tags: ["small", "cyan"]
}
4. Save and refresh GitHub Pages.

Name = the card name.
Image = your image path.
Code = your Valorant code.
Tags = search/filter words.

No generator, no yellow hero crosshair, and no related-crosshairs section are included.
Copy counts are local to each browser only.
